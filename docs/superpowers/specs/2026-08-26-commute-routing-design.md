# 전국 통합 출퇴근 길찾기 설계

## 목표

사용자가 지도에서 선택하거나 검색한 위치와 회사를 셔틀, 전국 대중교통, 도보로 연결하고 출발 시각 기준 추천 경로를 보여준다.

## 범위

- `회사 가기`: 선택 위치 -> 대중교통/도보 -> 최적 승차 정류장 -> 셔틀 -> 회사
- `퇴근하기`: 회사 -> 셔틀 -> 최적 하차 정류장 -> 대중교통/도보 -> 선택 위치
- 출발지는 현재 위치로 고정하지 않는다. 지도 탭 또는 장소 검색으로 선택한다.
- 사용자가 출발 날짜와 시각을 정한다.
- 대한민국 좌표 범위의 경로를 지원한다.
- 기존 셔틀 `stopOrder`, 정류장 시각, 회사 출발·도착 시각을 사용한다.

## 구조

브라우저는 셔틀 후보를 시간표와 직선거리로 먼저 줄인다. 후보별 첫 구간 또는 마지막 구간만 Cloudflare Worker에 요청하고, Worker가 Kakao 자동차·대중교통·도보 REST API를 호출한다. Kakao REST API 키는 Worker secret에만 저장한다.

길찾기 결과는 도보 1개, 택시 1개, 대중교통 3개 순서로 총 5개를 추천한다. 각 결과는 총 소요시간, 셔틀 노선과 탑승 시각, 승하차 정류장, 이동수단과 요금을 표시한다. API가 설정되지 않았거나 실제 경로를 반환하지 못하면 해당 추천은 표시하지 않는다.

## 지도 상호작용

- 정류장 선택은 해당 노선을 표시한다.
- 일반 지도에서 빈 배경을 짧게 탭하면 표시 중인 노선을 지우고 상세 패널을 닫는다.
- 길찾기 패널이 열린 동안 지도 터치와 마커 탭은 길찾기 단계와 선택 경로를 유지하며, 상세 패널이 확장된 경우 지도 터치·드래그·휠 줌 시작 시 지도 영역을 넓히도록 축소한다.
- 드래그와 줌은 노선과 현재 길찾기 단계를 유지한다.
- 셔틀 필터가 `전체`일 때 출근·퇴근 정류 이벤트를 모두 가진 정류장은 완전 불투명하게, 한 방향만 가진 정류장은 45% 흐리게 표시한다.

## 무료 운영

- GitHub Pages는 정적 앱을 계속 제공한다.
- Cloudflare Workers Free를 API 프록시로 사용한다.
- Kakao 자동차, 대중교통, 도보, 장소 검색 API 무료 쿼터 안에서 운영한다.
- 한 번의 길찾기에서 후보 정류장을 최대 5개로 제한한다.
- Cloudflare Rate Limiting binding으로 사용자당 분당 60회까지 Worker 요청을 허용한다.

## 검증

- 순수 함수 테스트: 시간 계산, 후보 선택, 양방향 상태, API 응답 변환.
- UI 계약 테스트: 지도 탭 해제, 드래그·줌 유지, 길찾기 입력과 결과 상태.
- 실제 모바일 브라우저에서 위치 선택, 출발 시각 변경, 출근·퇴근 결과, 오류 상태를 확인한다.
